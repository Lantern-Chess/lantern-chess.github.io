Getting Started

Playing with Lantern is easy.

Lantern is a chess engine rather than a complete graphical chess application, so it is loaded into a chess GUI.

1

Download

Download the newest Lantern release from the official Releases page.

2

Extract

Extract the downloaded ZIP file to a folder on your computer.

3

Add Engine

Open a UCI-compatible chess GUI and select Lantern.exe as an engine.

4

Play

Start a game, analyse a position, or let Lantern compete against another chess engine.
